# SerialMNT 0.2.0 发布说明

- 发布日期：2026-10-18
- 版本类型：开发版本（pre-1.0）

## 状态

开发版本，已通过自动化质量门禁；Windows/Linux 真实串口、单文件冷启动和长时间稳定性验收仍按发布清单执行。

## 新增

- Ymodem 单文件发送：支持 STX/1024 与 SOH/128 数据块、CRC-16/XMODEM、ACK/NAK 重试、EOT 收尾和接收端取消。
- 文件发送面板：文件选择、块大小、进度、百分比、速度、重试次数、耗时、失败原因和取消。
- 传输期间自动暂停手动发送、周期发送和终端内联发送，并禁用 DTR/RTS。
- 使用帮助窗口同步展示最新的用户手册内容。

## 变更

- 版本号由 `0.1.0` 提升到 `0.2.0`：新增用户可见功能，按预 1.0 语义化版本规则提升 MINOR。
- 用户手册新增“软件版本”章节，记录各版本的用户可见变更。
- 建立版本同步规则和 `scripts/check_version_sync.py`，CI 与构建脚本会校验版本号、文档版本头、实施计划版本、用户手册版本记录和随包手册副本。
- 新增根目录 `CLAUDE.md`，自动加载 `AGENT.md` 中的工程规则。

## 修复

- 修复使用帮助窗口不显示用户手册新增内容的问题：随包手册现在与 `docs/user-guide.md` 保持逐字节一致。

## 兼容性

- 配置 schema 不变，旧版 `settings.json` 可直接使用，无需迁移。
- 不新增第三方运行依赖。
- 仅支持 Ymodem 单文件发送；不支持接收、批量/目录传输、断点续传以及 XMODEM、ZMODEM。

## 已知限制

- Ymodem 要求 8 数据位、无校验且关闭 XON/XOFF 流控。
- 非 ASCII 文件名会转换为 ASCII，空格和特殊字符替换为下划线；文件名过长时拒绝发送。
- 低波特率下取消需要等待当前帧写完；传输中关闭会话的等待上限为 5 s。
- 尚未完成 Windows/Linux 真实串口硬件验收。
- 当前仅实际执行过 Windows 单文件构建；Linux 构建需在 Linux 环境验证。
- 不包含 Modbus 解析、脚本、日志回放和协议插件。
- 无代码签名、自动更新和遥测。
