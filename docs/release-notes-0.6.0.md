# SerialMNT 0.6.0 发布说明

- 发布日期：2026-10-18
- 版本类型：开发版本（pre-1.0）

## 状态

开发版本，已通过自动化质量门禁和 Windows 单文件构建；真实串口、桌面环境人工验收和长时间稳定性测试仍按发布清单在目标机器执行。

## 自 0.3.0 以来的版本

本版本合并发布 0.3.1、0.4.0、0.5.0 和 0.6.0 的变更。

## 新增

- 接收区 `Ctrl+F` 查找（0.4.0）：不区分大小写，`Enter`/`Shift+Enter` 循环跳转，右侧显示“当前/总数”或“无匹配”；只搜索接收区当前渲染的文本，不修改内存缓冲、原始字节和日志。
- 接收日志级别着色（0.5.0）：Error 红色、Warning 黄色、Pass 绿色、Debug 蓝色、Info 默认颜色，文本、HEX 和终端视图一致生效；☰ 菜单“日志级别颜色…”可修改字段、颜色并增删规则，规则全局生效并随配置保存。
- 接收区行号（0.6.0）：默认开启，按显示行从 1 编号，一条记录含多个换行时逐行编号，清屏或重绘后重新计数；行号只影响界面显示，终端视图不显示，开关随标签配置保存。
- 下拉选择框滚轮防护（0.3.1）：鼠标滚轮悬停在下拉框上不再误改端口、波特率、主题、字号等选项，滚轮继续用于滚动页面。

## 变更

- 接收标题行改为两行布局：首行是格式与操作，次行集中显示时间戳、行号、自动滚动、自动换行等选项；移除窗口变窄时的“⋯/更多显示选项”菜单，所有控件始终可见。
- “收起设置”和“终端/分栏”按钮改用与“暂停”“清屏”一致的描边按钮样式，默认状态有清晰轮廓。

## 兼容性

- 配置 schema 仍为 `1`，旧版 `settings.json` 可直接加载。
- 移除接收区 RX/TX 方向过滤：接收区始终同时显示两个方向，旧配置中的 `show_rx`、`show_tx` 字段会被忽略。
- 旧配置缺少 `show_line_number` 时按开启迁移。
