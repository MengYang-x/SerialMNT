# SerialMNT 0.7.0 发布说明

- 发布日期：2026-10-18
- 版本类型：开发版本（pre-1.0）

## 状态

开发版本，已通过自动化质量门禁和 Windows 单文件构建；真实串口、桌面环境人工验收和长时间稳定性测试仍按发布清单在目标机器执行。

## 自 0.6.0 以来的版本

本版本合并发布 0.6.1 的状态栏修复和 0.7.0 的会话页面切换过渡。

## 新增

- 会话页面切换过渡：新建会话或切换标签时，旧页面沿标签切换方向滑动 48 px，前段保持完全不透明，最后 35% 的位移进度内淡出，新页面实时显现。
- 切到右侧标签时旧页向右滑出，切到左侧标签时向左滑出；过渡约 0.36 秒，使用 `InOutSine` 缓动。
- 快速连续切换只保留最新一次过渡；窗口未显示时直接切换；过渡不改变串口连接、接收缓冲或配置。

## 修复

- 状态栏临时消息超时消失后自动隐藏状态栏，避免窗口底部残留空白（0.6.1）。

## 兼容性

- 配置 schema 仍为 `1`，旧版 `settings.json` 可直接加载。
- 不新增依赖，不改变串口收发、日志、CSV 字段或命令行行为。
