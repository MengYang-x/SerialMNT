# SerialMNT 0.7.2 发布说明

- 发布日期：2026-10-18
- 版本类型：开发版本（pre-1.0）

## 状态

开发版本，已通过自动化质量门禁和 Windows 单文件构建；真实串口、桌面环境人工验收和长时间稳定性测试仍按发布清单在目标机器执行。

## 自 0.7.0 以来的版本

本版本合并发布 0.7.1 和 0.7.2 的变更。

## 变更

- 串口设置中的“数据位”下拉框只提供 `8`；领域模型仍接受 5、6、7，旧配置可继续加载，重新连接时按 8 使用（0.7.1）。
- 使用帮助窗口正文中的链接改为在系统默认浏览器中打开，手册页首补充开发者主页链接（0.7.1）。

## 修复

- 修复接收区滚动到中间查看历史内容后，点击接收区会强制跳回记录底部的问题（0.7.2）。
- 自动滚动现在只在视图位于底部时跟随新记录；用滚轮、方向键或滚动条滚离底部后暂停，滚回底部后恢复。终端和分栏视图行为一致，暂停期间点击接收区或继续收到数据都不会跳回底部（0.7.2）。

## 兼容性

- 配置 schema 仍为 `1`，旧版 `settings.json` 可直接加载；旧配置中的 `bytesize=5/6/7` 仍可加载，重新连接时按 `8` 使用。
- 不新增依赖，不改变串口收发、日志、CSV 字段或命令行行为。
